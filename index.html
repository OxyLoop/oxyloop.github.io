MimoToon Shorts Uploader

A personal automation tool for managing my own YouTube channel, MimoToon, which publishes short, gentle animated stories for children.

What the app does

MimoToon Shorts Uploader runs privately for the owner of the MimoToon channel. It uses the YouTube API Services to:

  • upload finished animated Shorts to the MimoToon channel (as private videos by default);
  • set each video's title, description, tags, category, language and "made for kids" setting;
  • change a video's visibility (for example from private to public) after the owner has reviewed it;
  • read back the channel name, channel ID and the status of the channel's own videos to confirm that an upload or update succeeded.
Who can use it? Only the channel owner. This is not a public service: there is no sign-up, and no other users' Google accounts are connected to it. Google sign-in is used solely so the owner can authorise the tool to manage the owner's own channel.

Google user data

The app accesses only the data needed to upload and manage videos on the owner's own channel. It does not read viewers' data, comments, subscribers, watch history or contacts, and it never sells, shares or advertises with Google user data. The details are in the Privacy Policy.
