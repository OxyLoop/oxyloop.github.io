Privacy Policy

Effective date: 14 October 2026

This Privacy Policy explains how MimoToon Shorts Uploader ("the app") accesses, uses, stores and protects Google user data. The app is a personal automation tool operated by the owner of the MimoToon YouTube channel to upload and manage that channel's own videos. It is not offered to the public, and the only Google account connected to it is the channel owner's.

YouTube API Services. The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

1. Data the app accesses

With the owner's permission, granted through Google OAuth, the app requests these YouTube scopes:

PermissionWhy it is needed
youtube.uploadUpload finished videos to the owner's channel.
youtube.readonlyRead the channel's name and ID, and the status of the channel's own videos, to confirm that the correct channel is used and that an upload succeeded.
youtube.force-sslUpdate the title, description, tags, category, language, "made for kids" setting and visibility of the channel's own videos.

The data involved is limited to: the channel ID, channel name and handle; the IDs of videos uploaded by the app; and those videos' metadata and status (title, description, tags, category, privacy status, "made for kids" status, processing status).

The app does not access viewers' or subscribers' personal data, comments, messages, watch history, contacts, email, payment or analytics data, and it never accesses any other person's Google account.

2. How the data is used

  • Only to upload, update and verify videos on the owner's own channel, as listed above.
  • Not for advertising, profiling, analytics or marketing, and not to train AI or machine-learning models.
  • Not sold, rented or transferred to anyone.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. How OAuth credentials and data are stored

  • OAuth credentials (the OAuth client credentials and the refresh token that lets the app act for the owner) are stored only (a) on the owner's own computer, outside any source code, and (b) as encrypted secrets in the owner's private automation account (GitHub Actions encrypted secrets). They are never published, never written into source code or logs, and never shared with anyone.
  • Video records (channel ID, video IDs, upload status and the metadata the app wrote) are kept in a small private database used only to prevent duplicate uploads and to keep a history of the owner's uploads. It contains no credentials.
  • Access tokens are short-lived and kept only in memory while the app runs.

4. Sharing

Google user data is not shared with any third party. The app also uses AI services to create the animated videos (story writing, images, animation and narration). Those services receive only the creative instructions needed to make a video. They never receive Google user data, YouTube account data or OAuth credentials.

Data may only be disclosed if required by law.

5. Retention and deletion

  • OAuth credentials are kept only while the owner wants the app to manage the channel, and are deleted when access is revoked or the app is retired.
  • Video records are kept for as long as the corresponding videos exist on the channel, to prevent duplicate uploads, and can be deleted at any time on request.
  • Videos themselves are stored by YouTube and can be deleted in YouTube Studio.

6. How to revoke access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Select MimoToon Shorts Uploader and remove its access. After revocation the stored refresh token stops working immediately and the app can no longer access the channel. You can also ask for any stored records to be deleted using the contact details below.

7. Children's privacy

The MimoToon channel publishes content made for children, and every video is marked "made for kids" on YouTube. The app itself does not collect any information from children or other viewers: it only manages the owner's own videos.

8. This website

This website is a static information page. It uses no cookies, no analytics and no tracking, and it does not collect any personal information. It is hosted on GitHub Pages; GitHub may process standard technical information (such as IP addresses) as described in its own privacy statement.

9. Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date.
